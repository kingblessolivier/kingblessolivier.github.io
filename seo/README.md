# Personal-brand SEO

Working notes for one goal: when someone searches **"Nsengimana Olivier"**,
[nsolivier.me](https://nsolivier.me/) and
[github.com/kingblessolivier](https://github.com/kingblessolivier) should be on
the first page.

- **[playbook.md](playbook.md)** — the five-step strategy, what is already done
  in this repo, and what only you can do (bios, backlinks, Search Console).
- **[github-profile-readme.md](github-profile-readme.md)** — ready to paste into
  the `kingblessolivier/kingblessolivier` profile repo.

These files are documentation. They are deliberately **not** under `docs/`,
because on the Pages repo `docs/` is the published build output and
`npm run build` empties it.
